# Random Task Generator

**Автор:** Антонова Виктория Александровна

## Описание
Программа генерирует случайные задачи из категорий: Учёба, Спорт, Работа. Можно добавлять свои задачи и сохранять историю в JSON.

## Как запустить
1. Установите Python 3.7+
2. Скачайте random_task_generator.py
3. Запустите: python random_task_generator.py

## Как пользоваться
- Выберите категорию и нажмите "Сгенерировать задачу"
- Введите свою задачу и категорию, нажмите "Добавить"
- История сохраняется автоматически
